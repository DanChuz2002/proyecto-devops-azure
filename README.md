# Proyecto DevOps en Azure

Este proyecto implementa una infraestructura DevOps en la nube utilizando Microsoft Azure, Docker, Docker Swarm, Docker Hub y GitHub Actions.

## Tecnologías utilizadas

- Microsoft Azure Virtual Machine
- Ubuntu Server
- Docker
- Docker Swarm
- Python Flask
- Docker Hub
- GitHub Actions

## Endpoints de la aplicación

- `/`
- `/health`
- `/info`
