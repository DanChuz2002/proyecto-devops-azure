Cloud

Infraestructura desplegada en Microsoft Azure usando una máquina virtual Ubuntu.

Contenedores

Aplicación ejecutándose en Docker y orquestada mediante Docker Swarm.

CI/CD

Pipeline automático con GitHub Actions, Docker Hub y despliegue hacia Azure.

Base de Datos

PostgreSQL ejecutándose como servicio dentro del stack de Docker Swarm.

Endpoints disponibles

GET /health

Valida el estado de salud de la aplicación.

GET /info

Muestra información técnica del proyecto.

GET /db

Prueba la conexión con PostgreSQL e inserta registros.

GET / POST /api/visitas

API REST para consultar o crear registros en la base de datos.

GET /metrics

Métricas compatibles con Prometheus.
